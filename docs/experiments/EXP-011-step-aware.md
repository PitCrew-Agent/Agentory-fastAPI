# EXP-011 레시피 스텝 인지 이상 감지

## 목적·가설

Etch는 웨이퍼 한 장이 하나의 배치이고 그 안에 stabilization, main etch, over-etch 스텝
구간이 있는 배치성 공정입니다. 각 스텝은 정상 물리가 다르므로, 스텝 경계를 무시하는 통짜
시계열 모델은 스텝을 섞어 학습해 정상 분포가 넓어지고, 스텝 안의 임계 안쪽 이상을 놓칠 수
있습니다. FDC 정석은 스텝 정렬 후 스텝별 baseline에서 이상을 봅니다.

이 실험은 스텝 정렬이 실제로 감지를 개선하는지 정량화합니다. 시뮬레이터(골든 E2E·데모
공유)는 건드리지 않고 실험 전용 합성 생성기에 스텝 구조를 추가했습니다.

## 설정

- 생성기: src/anomaly/synthetic_step.py, 웨이퍼당 stabilization(40) → main etch(200) →
  over-etch(80) = 320 tick, 스텝 경계는 12 tick 선형 전이, 스텝별 채널 중심 상이
- 시나리오: normal, corr_break_main(main etch에서만 가스-압력 결합 소실), step_delay
  (stabilization 연장으로 스텝 경계 이동)
- 비교 3방식, 파라미터는 EXP-007 확정값 공유
  - agnostic: 통짜 PCA (스텝 무시)
  - agnostic+suppress: 통짜 PCA + 전이 억제 (현행 서빙 방식)
  - step-aware: 스텝별 PCA·한계, 스텝 인스턴스마다 EWMA 새로 시작
- 실행: experiments/exp_011_step_aware.py

## 결과

| 방식 | 정상 오탐/설비·일 | main etch 상관 붕괴 | 스텝 지연 |
| --- | --- | --- | --- |
| agnostic | 0.00 | 0.00 | 1.00 |
| agnostic+suppress (현행) | 0.00 | 0.00 | 1.00 |
| step-aware (alpha 0.10) | 0.00 | 0.50 | 1.00 |
| step-aware (alpha 0.15) | 0.00 | 1.00 | 1.00 |
| step-aware (alpha 0.20) | 0.00 | 1.00 | 1.00 |

## 발견 1: 통짜 모델은 스텝 안 이상에 장님

통짜 모델은 세 스텝을 섞어 학습해 정상 분포가 넓어집니다. 그 결과 main etch 안에서만
일어나는 임계 안쪽 상관 붕괴를 완전히 놓칩니다(recall 0.00). 전이 억제를 더해도 마찬가지
입니다. 전이 억제는 스텝 경계 오탐을 억누를 뿐 스텝별 좁은 기준을 제공하지 못하기
때문입니다.

## 발견 2: 스텝 인지가 스텝 안 이상을 회수

스텝별 모델은 main etch 그 스텝만의 좁은 baseline으로 판정해 같은 상관 붕괴를 잡습니다.
alpha 0.15 이상에서 recall 1.00을 오탐 0으로 달성합니다. 스텝 정렬이 통짜+전이 억제를
명확히 이깁니다.

## 발견 3: 스텝 인지는 인스턴스별 EWMA가 필수

구현 중 EWMA를 웨이퍼 경계 너머로 이어 돌리자 오탐이 144/설비·일까지 폭발했습니다. 스텝
인스턴스(웨이퍼별 구간)는 시간상 떨어져 있어 이어 누적하면 인위적 점프가 생깁니다. 스텝
인스턴스마다 EWMA를 새로 시작하니 오탐이 0으로 떨어졌습니다. 다만 인스턴스가 짧아 약신호
누적 시간이 줄어, alpha 0.10에서는 recall 0.50에 그쳤습니다. 스텝별 baseline이 좁아
잡음이 적으므로 더 빠른 누적(alpha 0.15)을 감당할 수 있어 이를 회수했습니다.

## 결론

스텝 정렬은 통짜+전이 억제 대비 명확한 개선입니다. main etch 안 상관 붕괴를 0.00에서
1.00으로, 오탐 증가 없이 회수합니다. 현행 전이 억제(EXP-008)는 스텝 신호 없이 동작하는
대용품이며, 스텝 인지가 정공법입니다.

## 한계와 후속

- 합성 데이터라 스텝 대비가 깨끗합니다. 실제 장비는 스텝 경계가 지저분해 스텝 정렬(어느
  tick이 어느 스텝인지) 자체가 어렵고, 정렬 오차가 감지를 흔들 수 있습니다
- 서빙에는 실제 레시피 스텝 신호가 필요합니다. 시뮬레이터·telemetry에 스텝 라벨이 없어
  현재는 실험 검증까지이며, 스텝 인지 서빙은 그 신호 확보가 전제입니다
- 후속: 스텝 인지 위에 마스킹 복원 모델을 얹어 스텝별 연쇄 관계를 학습 강제하는 실험
  (별도 진행)
