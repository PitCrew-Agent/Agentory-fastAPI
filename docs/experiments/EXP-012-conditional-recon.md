# EXP-012 마스킹 조건부 복원 검증

## 목적·가설

EXP-011에서 스텝 정렬의 실효를 입증한 뒤, 그 위에 마스킹 조건부 복원 접근을 검증합니다.
한 채널을 통째로 가리고 나머지 채널로 복원하도록 강제하면 변수 간 연쇄 관계 p(x_c |
x_다른채널) 학습이 유도되고, 변수별 복원 오차가 그대로 이상 스코어이자 기여도 분석이
됩니다.

가설 두 가지를 검증합니다. 첫째, 마스킹 목적함수가 상관 붕괴를 재구성 PCA보다 잘 분리
하는가. 둘째, 신경망(MLP) 복원의 비선형 이득이 연쇄가 비선형일 때 나타나는가.

## 설정

- 검출기: src/anomaly/models/conditional_recon.py (한 채널 마스킹, 나머지로 복원)
  - linear 모드: 채널별 릿지 회귀 (결정론·경량)
  - mlp 모드: 채널별 소형 신경망 (비선형 포착)
- 비교군: PCA both, PCA SPE 단독, VAR
- 데이터: 스텝 구조 합성 main etch 정착 구간 (스텝 인지 전제), 선형·비선형 연쇄와 전체·약한
  상관 붕괴
- 지표: 분리 배율(상관붕괴 점수 중앙값 / 정상 중앙값), 유예 recall, 기여도 적중(top_channel이
  깨진 쌍 gas·pressure에 속하는 비율)
- 실행: experiments/exp_012_conditional_recon.py

## 결과 (선형 연쇄)

| 검출기 | 분리 배율 | recall | 기여도 적중 |
| --- | --- | --- | --- |
| PCA both | 1.4 | 1.00 | 1.00 |
| PCA SPE | 1.5 | 1.00 | 0.67 |
| VAR | 2.2 | 1.00 | 1.00 |
| 조건부복원 linear | 4.2 | 1.00 | 1.00 |
| 조건부복원 mlp | 3.4 | 1.00 | 1.00 |

약한 붕괴(결합 40% 잔존)에서도 분리 배율은 조건부복원 linear 2.5로 최고이며 전 검출기
recall 1.00을 유지합니다.

## 발견 1: 마스킹 조건부 복원이 상관 붕괴를 가장 잘 분리

조건부복원 linear의 분리 배율이 4.2로 PCA(1.4)의 세 배, VAR(2.2)보다도 큽니다. 마스킹
목적함수가 변수 간 연쇄 학습을 강제해 상관 붕괴를 재구성보다 선명하게 드러낸다는 가설이
확인됐습니다.

## 발견 2: 기여도 정확도가 강점

조건부복원과 VAR은 기여도 적중 1.00으로 깨진 채널(gas·pressure)을 정확히 지목합니다.
PCA SPE 단독은 0.57~0.83으로 낮습니다. 변수별 복원 오차가 그대로 귀속 근거가 되어
에이전트 Tier 2 전달에 바로 쓸 수 있습니다.

## 발견 3: recall은 이미 포화, 분리 우위가 헤드라인 지표로 안 드러남

상관 붕괴가 main etch 전체에 지속돼 EWMA가 충분히 누적하므로, 분리 배율이 낮은 검출기도
recall 1.00을 달성합니다. 즉 조건부복원의 분리 우위는 현재 평가셋의 recall로는 환산되지
않으며, 더 약하거나 짧은 붕괴·조기 감지·기여도 정밀도에서 이득이 나타납니다.

## 발견 4: MLP가 linear를 못 이김, 비선형 가설 기각

MLP 모드는 선형 모드보다 오히려 낮은 분리(3.4 vs 4.2)를 보이며, 비선형 연쇄 합성에서도
동일합니다. 예상했던 "비선형 연쇄면 MLP 승"은 성립하지 않았습니다. 도입한 포화(tanh)
비선형이 약하고 MLP가 소폭 과적합한 것으로 해석하며, 현재 데이터에서는 선형 조건부
복원으로 충분합니다.

## 결론

마스킹 조건부 복원은 상관 붕괴 분리와 기여도 정확도에서 확실한 강점입니다. 다만 현재
평가셋은 recall이 포화되어 확정 스택(PCAX + EWMA + VAR)을 헤드라인 지표로 넘어서지
못합니다. 채택 판단은 다음 이득이 필요한 시점으로 미룹니다.

- 기여도 정밀도가 중요한 에이전트 Tier 2 전달 강화
- 더 약하거나 짧은 상관 붕괴, 실측 데이터의 지저분한 정상
- 비선형 연쇄가 강한 실측 데이터 (합성의 약한 비선형에서는 MLP 이득 없음)

linear 조건부 복원은 결정론·경량이라 이 이득이 확인되면 VAR 옆에 세 번째 보완 경로로
저비용 통합이 가능합니다. MLP는 현재 근거로는 불필요합니다.

## 한계

- 합성 연쇄가 단순·약한 비선형이라 MLP의 여지가 제한적, 실측의 강한 비선형에서 재검증
  필요
- recall 포화로 분리 우위의 실익(조기 감지)을 이 평가셋에서 깨끗이 측정하지 못함, 조기
  감지 지표는 경계 전이·EWMA 초기화 잡음으로 신뢰도가 낮아 보고에서 제외
