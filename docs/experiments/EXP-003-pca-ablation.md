# EXP-003 PCA MSPC ablation

## 목적·가설

EXP-002의 첫 설정값(윈도우 60·stride 12·분위수 0.997·유지분산 0.9)은 근거 없는 초기값
이므로, 4축 그리드 36조합으로 지연-오탐 곡선을 그려 v0 config를 데이터로 확정합니다.

## 설정

- config: experiments/configs/exp_003_pca_ablation.yaml
- 그리드: 윈도우 [24, 60, 120] x stride [6, 12] x 분위수 [0.99, 0.997, 0.999] x
  유지분산 [0.9, 0.95] = 36조합
- 전 조합 지표: experiments/results/exp_003.json의 grid 항목 (MLflow에도 조합별 기록)
- 선정 기준: recall 1.0 조합 중 오탐/설비·일 최소, 동률 시 지연 p90 → mean

## 결과

선정 config와 주요 비교점은 다음과 같습니다.

| config | 오탐/설비·일 | recall | 지연 p90 |
| --- | --- | --- | --- |
| **w24 s12 q0.999 c0.9 (선정)** | **0.53** | 1.000 | 11 |
| w24 s12 q0.997 c0.9 | 2.93 | 1.000 | 11 |
| w60 s12 q0.997 c0.9 (EXP-002 초기값) | 5.87 | 1.000 | 11 |
| w120 s6 q0.99 c0.95 (최악) | 38.40 | 1.000 | 11 |

축별 민감도는 뚜렷하게 갈렸습니다.

1. **분위수가 오탐을 지배합니다.** 0.99 → 0.999에서 오탐이 조합 불문 한 자릿수로
   떨어집니다 (예: w24 s12 기준 10.67 → 0.53).
2. **짧은 윈도우(24)가 유리합니다.** 같은 조건에서 w24가 w60·w120보다 오탐이 낮습니다.
   긴 윈도우는 정상 변동이 피처에 더 많이 섞여 정상 분포 자체가 넓어지는 것으로
   해석합니다.
3. **stride 12가 6보다 오탐이 낮습니다.** 채점 기회 자체가 절반이라 확률적 이탈 기회도
   절반이 되는 구조적 효과이며, 지연 손해는 없었습니다 (아래 4).
4. **지연 p90은 전 조합에서 11 tick으로 동일합니다.** 지연 꼬리는 급성이 아니라
   드리프트가 결정하는데, 드리프트는 기울기 피처에 신호가 누적되는 시간(약 11 tick)이
   필요해 stride·윈도우와 무관하게 고정됩니다. 즉 이 그리드에서 지연은 튜닝 대상이
   아니었고, 오탐 최소화만이 실질 목표였습니다.
5. 유지분산은 0.9가 0.95보다 일관되게 낮은 오탐을 보였습니다.

## 결론

v0 config를 **윈도우 24 tick(2분)·stride 12 tick(1분)·분위수 0.999·유지분산 0.9**로
확정합니다. 규칙 베이스라인 대비 오탐 72.8 → 0.53건/설비·일 (-99.3%), recall·지연 p90
유지입니다. EXP-005(TS2Vec)는 이 config의 windowing을 공유하고 encoder·거리만 교체해
비교합니다.

## 한계

- 선정 config의 오탐이 절대 건수 2건이라 추정 분산이 큽니다. 정상 관측이 3.75
  설비·일뿐이라 0.53건/일은 상한 신뢰구간이 넓으며, 평가 세트 v2에서 정상 구간을
  늘려 재확인이 필요합니다.
- q=0.999는 학습 윈도우 약 2,900개 중 상위 3개 수준의 극단 분위수라 한계 추정 자체가
  불안정합니다. 학습 데이터가 늘면 한계도 재캘리브레이션해야 합니다.
- 오탐 2건짜리 지표로 config를 고르는 것은 선택 노이즈 위험이 있습니다. v2에서 상위
  조합(w24 s12의 q0.997~0.999)만 재검증하는 축소 그리드로 확인합니다.
