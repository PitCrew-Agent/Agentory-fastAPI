# EXP-004 평가 세트 v2 구축·재채점

## 목적·가설

평가 세트 v1은 규칙 레이어가 원리적으로 전부 잡는 이상만 담고 있어(EXP-001 한계 1),
새 레이어의 존재 이유인 임계 안쪽 이상을 검증할 수 없었습니다. 식각 챔버의 물리 결합
(Gas → Pressure, RF → Pressure·Temp)을 모사하는 합성 생성기를 추가해 v2를 구축하고,
규칙·v0(PCA MSPC)·v0 변형(상관 피처 추가, PCAX)을 재채점했습니다. 가설은 "임계 안쪽
이상에서 규칙 recall이 무너지고 v0가 그 일부를 회수한다"였습니다.

## 설정

- 세트: data/eval/v2 (27세그먼트 = v1 15개 seed 불변 + 합성 12개, 정답 이벤트 22건)
- 합성 시나리오: corr_break x2, osc_propagation x2, inband_drift x2, ignition x2 (정상
  라벨), 정상 x4. 생성기는 src/anomaly/synthetic.py, 규칙 판정은 simulator와 동일 의미론
- config: exp_004_rule_v2 / exp_004_pca_v2 / exp_004_pcax_v2 (v0는 EXP-003 확정값 고정)
- 감지 유예 60 tick(5분): 장구간 이벤트에서 배경 오탐의 우연 적중으로 recall이
  포화하는 문제(아래 발견 1)를 차단

## 결과

유형별 recall (유예 60 tick 기준):

| 이상 유형 | 규칙 | v0 (PCA) | v0 변형 (PCAX) |
| --- | --- | --- | --- |
| acute (7) | 1.00 | 1.00 | 1.00 |
| drift (8) | 1.00 | 1.00 | 1.00 |
| variance (1) | 1.00 | 1.00 | 1.00 |
| oscillation (2) | **1.00** | 0.50 | 0.50 |
| corr_break (2) | **0.00** | 0.00 | 0.00 |
| drift_inband (2) | 0.50 (우연) | 0.00 | 0.00 |
| 오탐/설비·일 | 116.7 | **4.7** | 5.3 |

유예 없이 본 이벤트별 실제 감지 지연 (tick):

| 이벤트 | 규칙 | v0 | 해석 |
| --- | --- | --- | --- |
| corr_break x2 | 129 / 136 | 131 / 143 | 양쪽 다 배경 수준, 실질 미감지 |
| oscillation x2 | 5 / 12 | 23 / 83 | 진동이 밴드를 스쳐 규칙이 즉시 감지 |
| drift_inband x2 | 260 / 17 (우연) | **695 / 419 (실제)** | 규칙은 WRN-701 발생 0 (원리적 불가) |

## 발견

1. **이벤트 recall은 장구간 이벤트에서 우연 적중으로 포화합니다.** 유예 도입 전 규칙
   recall이 1.0으로 나왔는데, 3,600 tick 이벤트 구간에 배경 오탐(tick당 약 0.3%)이
   우연히 떨어질 확률이 사실상 1이기 때문입니다. 감지 유예와 유형별 recall 분해를
   평가기에 추가해 차단했습니다.
2. **규칙 레이어의 임계 안쪽 사각이 입증됐습니다.** in-band 드리프트에서 WRN-701 발생
   0건 (밴드가 중심을 추종하므로 원리적 불가), 상관 붕괴 감지 0. 반면 v0는 in-band
   드리프트를 35~58분에 실제 감지합니다 (규칙은 영원히 불가).
3. **v0 계열은 상관 붕괴 조기 감지가 불가합니다.** 채널 쌍 상관 피처를 추가(PCAX)해도
   지연 131/143 → 131/119로 사실상 동일합니다. 신호가 윈도우당 약 3sigma 수준이라
   q0.999 단발 임계를 넘지 못하는 구조적 한계이며, 남은 레버는 두 가지입니다:
   점수 시계열 누적(EWMA/CUSUM, v0 확장) 또는 표현 자체의 교체(TS2Vec, EXP-005).
4. **모드 전이(점화)에서 규칙이 대량 오탐을 냅니다.** 램프 118 tick 내내 WRN-701 연속
   발령 (2세그먼트 237건, 규칙 오탐 788건의 30%). v0는 총 오탐 32건에 그칩니다.
   다중 모드 정상 처리에서도 학습 기반이 우위임이 확인됐습니다.
5. **oscillation은 규칙이 더 빠릅니다** (5/12 vs 23/83 tick). 진동 폭이 밴드를 스치는
   설정이라 급성 코드가 즉시 반응한 것으로, 레이어드 구조(D1)의 근거가 하나 더
   추가됐습니다.

## 결론

v2로 "규칙이 못 보는 영역"이 정량화됐고, 그 영역에서 v0의 성과는 in-band 드리프트
회수에 그쳤습니다. corr_break 조기 감지가 EXP-005(TS2Vec + kNN)의 명확한 판정
기준이 됩니다: TS2Vec가 corr_break를 유예 안에 감지하지 못하면 v0 + EWMA/CUSUM
확장이 우선 대안입니다.

## 한계

- 합성 결합 동역학은 선형·고정 지연이라 실제 챔버의 비선형 결합보다 단순합니다
- oscillation 진폭(1.2sigma)이 밴드 가시권에 걸쳐 있어 "순수 임계 안쪽 진동" 검증은
  진폭을 낮춘 시나리오가 별도로 필요합니다
- drift_inband의 유예 60 tick은 전개 속도(375 tick) 대비 물리적으로 불가능한 요구라
  해당 유형 recall은 0이 구조적 기본값이며, 유형별 유예 차등은 도입하지 않고 이벤트별
  지연 표로 보완했습니다
