# EXP-015 관계 붕괴 검출 강건성 스트레스

## 목적·가설

고정 평가 세트 v2는 `corr_break`(가스-압력 결합 소실) 세그먼트가 2건(SYN-B01/B02)뿐입니다.
이 2건에서 통계 recall 1.0·규칙 recall 0.0이 나오고, ADR-0010은 이를 근거로 "규칙이 관계
붕괴를 원리적으로 감지 불가"라고 서술합니다. 표본 2건에 기댄 일반화가 넓은 표본에서도
유지되는지, 통계 검출률이 표본 특성이 아닌 실제 성능인지 검증합니다.

가설: 통계 recall은 100% 미만으로 내려가고, 규칙 recall은 0을 초과합니다(시나리오가
관계만 깨는 것이 아니라 pressure 잡음도 키워 일부 실현에서 밴드 이탈을 유발).

## 설정

- 생성: `eval_set`의 `rng = Random(f"{seed}:{equipment_id}")` 구조를 이용해 장비 ID·base
  seed만 바꿔 동일 `corr_break` 시나리오의 독립 실현을 다수 생성
- 규모: base seed 4개 × corr_break 80건 = 총 320 인스턴스, seed당 정상 4건 병행
- 채점: 통계는 서빙 최종 구성 `exp_008_suppress`(윈도우 12·stride 6·q0.999·EWMA α0.1·
  클리핑 3.0·K2·전이 억제·유예 180 tick), 규칙은 `exp_004_rule`(유예 60 tick)
- 학습: v2 train 설정 재사용(EtchingCoupled 정상), 모델은 공정 유형 단위 적합
- 실행: `experiments/exp_015_corrbreak_stress.py`, 결과 스냅샷
  `experiments/results/exp_015_corrbreak_stress.json`

## 결과

| base seed | 통계 recall | 규칙 recall | AUC-PR |
| --- | --- | --- | --- |
| 20260716 | 0.787 (63/80) | 0.288 (23/80) | 0.996 |
| 11111 | 0.925 (74/80) | 0.312 (25/80) | 0.996 |
| 77777 | 0.812 (65/80) | 0.338 (27/80) | 0.996 |
| 20260101 | 0.887 (71/80) | 0.388 (31/80) | 0.998 |
| **합계 (320건)** | **0.853 (273/320)** | **0.331 (106/320)** | **0.996** |

- 통계 corr_break 평균 감지 지연 81.1 tick(약 6.8분), AUC-PR은 v2(0.995)와 정합
- 통계/규칙 검출률 비 2.58배

## 해석

- 통계 검출률은 표본 특성이 아닌 실제 성능입니다. 4개 base seed에서 0.79~0.93으로 안정적이며,
  v2의 1.0(2/2)은 표본 2건이 우연히 전부 잡힌 상단값이었습니다. 넓은 표본 기준 약 85%가
  정직한 수치입니다.
- 규칙 recall 0.0은 v2 2건 한정입니다. 넓은 표본에서 규칙은 약 33%를 잡습니다. 원인은
  `corr_break` 시나리오가 관계만 깨는 것이 아니라 pressure 잡음을 σ 0.5→0.86으로 키우기
  때문이며(`synthetic.generate_rows`), 일부 실현에서 pressure가 밴드를 이탈해 규칙이
  부수적으로 발령합니다. 규칙이 관계 붕괴 자체를 인지하는 것은 아니고 변량 증가의 증상을
  잡는 것이지만, recall 집계로는 33%입니다.
- 따라서 "규칙이 관계 붕괴를 원리적으로 감지 불가"라는 서술은 지나칩니다. 정확히는 "각
  채널이 밴드 안에 머무는 순수 관계 붕괴는 단일 변량 규칙이 인지·귀속할 수 없고, v2 2건이
  마침 밴드를 넘지 않아 recall 0.0으로 측정됨"입니다. 넓은 표본의 실증 비교는 통계 85% 대
  규칙 33%(2.58배)입니다. ADR-0010/0011의 corr_break recall 0.0 서술에 이 각주를 반영합니다.
