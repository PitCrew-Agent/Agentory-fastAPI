# EXP-000 고정 평가 세트 구축

## 목적·가설

이후 모든 실험(EXP-001~)을 동일 기준으로 채점하기 위한 고정 평가 세트를 구축합니다.
simulator의 순수 생성 로직과 시나리오 정의를 재사용하므로, 급성·드리프트·변동성·복합
이상이 주입 시점(정답 라벨)과 함께 결정론적으로 생성됩니다. 별도 모델 없이 데이터와
평가 체계만 확정하는 실험입니다.

## 설정

- config: experiments/configs/exp_000_eval_set.yaml
- 생성 코드: src/anomaly/eval_set.py
- git commit: 83c5f07eae5cbe99c4f3b2088de3d97e9bf9930d
- seed: eval 20260716 / train 20260701 (설비 ID와 함께 격리)
- tick 1개 = 5초 (simulator 기본 주기)

## 구성

| 구분 | 내용 | 규모 |
| --- | --- | --- |
| 평가 세트 | 세그먼트 15개 x 4,320 tick (6시간), 워밍업 720 tick 후 이상 주입 | 64,800 행 |
| 학습 세트 | 정상 전용 설비 4대 x 17,280 tick (24시간) | 69,120 행 |
| 정답 이벤트 | (설비, 이상 유형, 대상 변수) 단위 | 16건 |

세그먼트 배치는 정상 2, 급성 4 (변수 4종 전체), 드리프트 4 (변수 4종 전체), 변동성 1,
복합 4 (mixed_pm_demo 포함)로 구성해 시나리오 공간을 전부 커버합니다. 규칙 레이어
판정(alarm_code, 변수별 코드)을 행마다 함께 저장하므로 EXP-001 베이스라인 채점에
추가 실행이 필요 없습니다.

## 산출물

```
data/eval/v1/
  eval.parquet          평가 세트 본체 (424 KB)
  train_normal.parquet  정상 전용 학습 세트 (522 KB)
  events.json           정답 이벤트 16건
  manifest.json         config 스냅샷 + git commit + 행 수
```

같은 config면 항상 동일 산출물이 재생성되며, 설비별 독립 rng라서 세그먼트를 추가해도
기존 세그먼트 값은 변하지 않습니다. 용량이 작아 git 커밋으로 얼려두는 방식을 권장합니다.

## 결론

평가 세트 v1을 확정합니다. 이후 실험은 본 세트로만 채점하며, 세트 변경이 필요하면
v2를 새로 생성하고 실험 문서에 어느 버전으로 채점했는지 명시합니다. 후속은 EXP-001
(현행 규칙 레이어 단독 채점)로 베이스라인 지표를 확보하는 작업입니다.

## 한계

- simulator 합성 데이터라 실측 센서의 비정상성(레시피 전환·재기동 등)은 미반영, 실
  데이터 확보 시 v2에서 보강 필요
- 드리프트 이벤트의 정답 시작을 주입 시점(drift_start_tick)으로 정의하므로, 주입 직후
  구간은 물리적으로 정상과 거의 동일해 감지 지연 지표가 보수적으로 측정됨

## v2 (EXP-004에서 구축)

v1의 한계(임계 안쪽 이상 부재)를 보완한 v2를 data/eval/v2에 동결했습니다. v1 세그먼트
15개는 seed 불변으로 그대로 포함되어 v1 결과와 비교 가능하며, 식각 챔버 물리 결합을
모사하는 합성 생성기(src/anomaly/synthetic.py, 공정 유형 EtchingCoupled)로 12개
세그먼트를 추가했습니다: 정상 4, corr_break 2, osc_propagation 2, inband_drift 2,
ignition 2 (점화 램프업, 정상 라벨). 학습 세트에도 합성 정상 4대를 추가해 총 8대
138,240행입니다. 상세 결과는 EXP-004-eval-v2-rescore.md 참고 바랍니다.
