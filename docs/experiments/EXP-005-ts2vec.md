# EXP-005 TS2Vec + kNN 거리 (v1 후보)

## 목적·가설

EXP-004에서 확정한 판정 기준 "corr_break를 유예 60 tick 안에 감지하는가"로 v1 후보
(TS2Vec encoder + kNN 거리)를 검증합니다. 부가로 최초 구상이었던 단일 centroid cosine
방식을 대조군으로 함께 채점해 D3(임베딩 은행 + kNN) 선택을 확인합니다.

## 설정

- 구현: src/anomaly/models/ts2vec.py, TS2Vec(AAAI 2022)의 압축 구현 (dilated conv
  encoder, timestamp 마스킹, 계층적 instance+temporal 대조 손실, max pool 임베딩)
- 단순화 2가지: crop을 24 tick 윈도우 내부에서 샘플링 (원 논문은 긴 시계열), CPU 고정
  학습 (MPS 비결정성 회피)
- windowing은 EXP-003 확정값 공유 (w24 s12), 공정 유형별 encoder 3개 학습
- config: exp_005_ts2vec (kNN, k=5) / exp_005_cosine (centroid cosine), 유예 60 tick
- repr 64차원, depth 6, 600 iter, seed 고정 (재실행 시 동일 결과 확인)

## 결론

**v1 채택을 보류합니다.** 판정 기준인 corr_break에서 점수 분포가 이상 전후 동일해
(0.73 → 0.73) 감지 지연의 문제가 아니라 표현에 신호 자체가 없습니다. 대조 학습이
지배적인 AR 동역학 위주로 표현을 형성하고 채널 간 미세 결합 구조를 보존하지 않는
것으로 해석합니다. 그 외 영역에서는 v0 대비 오탐 소폭 우위(4.74 → 3.70), 지연 소폭
열위(p90 15.8 → 23)로 교체 근거가 없습니다.

D3는 방향이 확인됐습니다: 같은 encoder에서 kNN 은행이 cosine centroid보다
oscillation recall 0.50 vs 0.00으로 우세합니다.

corr_break의 남은 레버는 점수 시계열 누적입니다. PCAX의 상관 피처는 윈도우당 약
3sigma의 지속 신호를 이미 산출하므로(EXP-004 발견 3), EWMA/CUSUM 누적이 단발
임계의 한계를 넘을 가장 저렴한 경로이며 EXP-006에서 검증합니다.

## 한계

- 압축 구현·짧은 문맥(24 tick)·미튜닝 상태의 결과이므로 "TS2Vec 일반의 기각"이 아니라
  "이 구현·이 설정에서 v0 초과 근거 없음"입니다. 긴 문맥 encoder 재도전은 실측 데이터
  확보 후 판단합니다
- 점화(ignition) 흡수 검증은 미수행입니다. 학습 세트에 점화 구간이 없어 은행에 해당
  모드가 없기 때문이며, 다중 모드 은행 구성은 EXP-006 캘리브레이션과 함께 다룹니다
