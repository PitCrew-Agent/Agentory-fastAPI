# 이상 감지 실험 종합 요약

전 실험(EXP-000~015)의 평가지표, 베이스라인 대비 비교, 채택 논리, 최종 스택을 한 곳에
정리한 문서입니다. 각 실험의 상세는 개별 EXP 문서를, 설계 결정 이력은 decisions.md를
참고하시면 됩니다.

> **재캘리브레이션 반영 (2026-07-29, [ADR-0011](../adr/0011-anomaly-eval-metrics.md))**: 아래 v2 표는 실험 당시 채점(전 유형 공통 유예, 오탐 raw FAR) 기준입니다. 이후 유형별 감지 유예(drift_inband 720 tick)와 운영 정합 dedup FAR이 도입되어, 재기록 스냅샷에서는 채택 스택 event_recall이 **0.91→1.000**, 헤드라인 오탐이 **dedup FAR 0.59건/설비·일**로 바뀌었고, 동일 오탐 예산에서 PCA-both가 최우수임이 확인되었습니다. 재캘리 후 검출기 비교표·운영점 비교의 단일 소스는 [anomaly-model-summary.md](anomaly-model-summary.md)입니다.

## 평가지표

이상 감지는 단일 정확도로 평가할 수 없습니다. 놓치면 사고이고 너무 자주 울리면 운영자가
무시하기 시작하므로, 상충하는 네 지표를 함께 봅니다. 지표 정의의 단일 소스는
`anomaly.evaluation.summarize`입니다.

| 지표 | 정의 | 방향 | 왜 중요한가 |
| --- | --- | --- | --- |
| event recall | 정답 이벤트 중 구간 내 판정 1건 이상 비율 (유형별 분해) | 높을수록 | 놓침은 사고 |
| 오탐/설비·일 (raw) | 이벤트 밖 판정 수 / (설비 x 관측일) | 낮을수록 | 실험 내부 비교용 |
| 오탐/설비·일 (dedup) | 30분 고정버킷당 1건으로 축약한 운영 정합 오탐 (ADR-0011) | 낮을수록 | 운영자 실제 체감, 현 헤드라인 |
| 감지 지연 | 이벤트 시작부터 첫 판정까지 tick (5초/tick), 유형별 유예 | 낮을수록 | 조기 감지 가치 |
| AUC-PR | 임계 무관 점수 순위 품질 | 높을수록 | 모델 간 순수 비교 |

recall만 높은 것은 무의미하며, 목표는 recall 유지 + 오탐 최소 + 지연 단축입니다.

## 평가셋

두 세트를 썼고 서로 직접 비교되지 않으므로 표를 분리합니다.

| 세트 | 구성 | 목적 |
| --- | --- | --- |
| v1 | simulator 시나리오 (급성·드리프트·변동성) | 규칙이 잡는 이상, 초기 파이프라인 검증 |
| v2 | v1 + 합성 결합채널 (상관붕괴·in-band 드리프트·진동·점화) | 규칙이 못 잡는 임계 안쪽 이상 |

## v1 진화 (파이프라인·오탐 최적화)

| 실험 | recall | 오탐/설비·일 | 비고 |
| --- | --- | --- | --- |
| EXP-001 규칙 베이스라인 | 1.00 | 72.8 | 기준선 |
| EXP-002 PCA MSPC | 1.00 | 5.87 | v0 후보 |
| EXP-003 ablation 확정 | 1.00 | 0.53 | 윈도우·분위수 튜닝 |

v1은 규칙이 잡는 이상만 담아 recall이 구성상 1.00이며, 여기서는 오탐 감축이 핵심 전선
이었습니다.

## v2 종합 비교 (모델·구조 선택, 채택은 볼드)

| 실험 / 방식 | recall | 상관붕괴 | 상관 지연 | 진동 지연 | 오탐/설비·일 |
| --- | --- | --- | --- | --- | --- |
| 규칙 베이스라인 | 0.86 | 0.00 | 미감지 | 미감지 | 116.7 |
| PCA MSPC v0 (단발) | 0.77 | 0.00 | 미감지 | 미감지 | 4.7 |
| EWMA 확정 (EXP-006) | 0.91 | 1.00 | 125 | 59 | 19.9 |
| 실시간 60/30/K2 (EXP-007) | 0.91 | 1.00 | 104 | 26 | 17.5 |
| **전이 억제 (EXP-008, 채택)** | **0.91** | **1.00** | **104** | **26** | **3.7** |
| VAR 단독 (EXP-009) | 0.91 | 1.00 | 23 | 116 | 4.4 |
| Autoencoder (EXP-009) | 0.91 | 1.00 | 95 | 65 | 3.4 |
| Kernel PCA (EXP-009) | 0.86 | 0.50 | 149 | 29 | 3.1 |
| Isolation Forest (EXP-009) | 0.82 | 0.00 | 미감지 | 38 | 13.2 |
| **병합 PCA+VAR (EXP-010, 채택 옵션)** | **0.91** | **1.00** | **26** | **29** | **4.0** |

## 채택 논리

1. 베이스라인 대비 도약: 규칙 오탐 116.7 → 3.7 (-97%), 상관붕괴 0.00 → 1.00. EWMA
   누적(약신호 감지)과 전이 억제(점화 오탐 제거)가 주역입니다.
2. 최신성 가설 반증: Kernel PCA는 상관붕괴 0.50으로 악화, Autoencoder는 동급(3.4 vs
   3.7)이라 교체 이득 없음, Isolation Forest는 상관붕괴 0.00·오탐 13.2로 탈락. 성패는
   모델 최신성이 아니라 메커니즘 계열(재구성 잔차)이 결정합니다.
3. 거리 계열 삼중 기각: TS2Vec+kNN(EXP-005)·UMAP·Isolation Forest 모두 상관붕괴에
   실패했습니다. 이 신호는 기하학적 거리가 아니라 재구성 잔차·시간 누적으로 표현됩니다.
4. VAR 보완: 상관붕괴 지연을 104 → 23으로 4.5배 당기나 진동은 116으로 느려져, 대체가
   아니라 병합으로 추가합니다. 병합은 상관붕괴 26 + 진동 29로 양쪽 강점을 취합니다.

## 스텝 구조·견고성 실험 (EXP-011~015, 별도 데이터)

v2가 아니라 배치성 스텝 구조 합성 데이터(웨이퍼당 stabilization·main etch·over-etch)라
위 표와 분리합니다. 세 실험은 스텝 정렬 → 마스킹 복원 → 지저분한 정상으로 이어집니다.

### EXP-011 스텝 인지

| 방식 | main etch 상관붕괴 | 오탐/설비·일 |
| --- | --- | --- |
| 통짜 + 전이 억제 (현행) | 0.00 | 0.00 |
| **스텝 인지 (alpha 0.15)** | **1.00** | **0.00** |

통짜 모델은 세 스텝을 섞어 학습해 스텝 안 임계 안쪽 이상에 장님입니다. EXP-008 전이
억제는 스텝 신호 없는 대용품이며 스텝 인지가 정공법입니다. 서빙에는 실제 레시피 스텝
신호가 전제라 현재는 실험 검증까지입니다.

### EXP-012 마스킹 조건부 복원

한 채널을 가리고 나머지로 복원, 변수별 복원 오차가 이상 스코어이자 기여도입니다.

| 검출기 | 상관붕괴 분리 배율 | 기여도 적중 |
| --- | --- | --- |
| PCA both | 1.4 | 1.00 |
| VAR | 2.2 | 1.00 |
| **조건부복원 linear** | **4.2** | **1.00** |

마스킹이 연쇄 학습을 강제해 분리가 최고이고 기여도가 정확합니다. 다만 recall이 포화되어
확정 스택을 헤드라인 지표로 못 넘어 채택은 보류하며, 기여도 정밀도·약한 붕괴·실측 강한
비선형에서 재판단합니다. MLP는 linear를 못 이겨(비선형 가설 기각) 통합 시 linear로 충분합니다.

### EXP-013 지저분한 정상

recall 포화의 원인이 깨끗한 정상이라 보고, 런투런 변동·센서 글리치를 주입해 변별했습니다.

| 검출기 | 지저분한 정상 상관붕괴 최대배율 | 감지 |
| --- | --- | --- |
| PCA T² (크기) | 1.09 | 미감지 |
| **PCA SPE (관계)** | **2.83** | **감지** |
| **VAR (관계)** | **9.82** | **감지** |
| **조건부복원 (관계)** | **8.50** | **감지** |

지저분한 정상에서 크기 기반 T²는 baseline이 넓어져 상관 붕괴를 놓치고, 관계 기반은 오히려
강해집니다. 이는 확정 스택이 T² 단독이 아니라 SPE 관계 잔차 누적을 corr_break 경로로 쓴
설계를 실측 근접 조건에서 사후 정당화합니다.

### EXP-014 견고성 경계 스윕

지저분함 강도(messy_scale 0~4)를 스윕해 관계 기반의 견고 구간을 확인했습니다. 관계 기반
(SPE·VAR·조건부복원)은 전 강도에서 상관붕괴를 감지하고 오탐 0.02 이하를 유지하나, 크기 기반
T²는 중간 강도(0.5~2.0)에서 baseline 팽창으로 상관붕괴를 놓치는 사각이 있습니다. EXP-013을
곡선으로 확장해 SPE 관계 경로의 강도 축 우위를 재확인합니다.

### EXP-015 상관붕괴 스트레스

넓은 표본(다중 시드)으로 상관붕괴 감지를 스트레스 테스트했습니다. 통계 레이어 recall 0.853,
규칙 레이어 recall 0.331로, 규칙이 상관붕괴를 약 33% 부수 감지합니다. 이는 앞선 실험의 "규칙은
상관붕괴를 원리적으로 감지 불가(recall 0.0)"라는 일반화를 완화하며, 좁은 표본의 우연이 아니라
넓은 표본에서 통계 레이어의 상관붕괴 우위(약 2.58배)가 유지됨을 보입니다.

## 최종 채택 스택

```
규칙 임계 (유지)          급성·안전, 포인트 단위 즉시
  +
PCAX 재구성 (T²·SPE)      급성·드리프트·진동
  + EWMA 누적             상관 붕괴 등 약신호
  + 전이 억제             점화 모드 전이 오탐 제거
  + 지속 K=2              고립 스파이크 억제
  +
VAR 보완 경로 (옵션)      상관 붕괴 조기 감지 (지연 26)
  +
LLM                     판정 아닌 설명 (T²/SPE 채널 기여도)
```

서빙 파라미터: 윈도우 60초 / stride 30초 / K=2. 설비별 임계 캘리브레이션·baseline drift
자동 갱신·섀도우 모드 포함. 상세는 docs/anomaly-serving.md를 참고하시면 됩니다.

## 한계

- 위 수치는 합성 시뮬 데이터 기준의 천장입니다. 실제 장비는 정상 변동이 더 지저분해
  현장 오탐은 이보다 높을 것으로 예상되며, 그래서 섀도우 모드로 먼저 관찰합니다
- EXP-013이 지저분한 정상을 근사했으나 런투런 오프셋·센서 글리치 두 종에 그치며, 실측은
  다중 모드 전이·정비 후 거동 변화 등 더 다양해 실측 정상 분포로 재검증이 필요합니다
- 스텝 인지·마스킹 복원 채택·설비 개체차·전이 임계 실측 재조정은 모두 실제 팹 데이터 확보가
  전제입니다
