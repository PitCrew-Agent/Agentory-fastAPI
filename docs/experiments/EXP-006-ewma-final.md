# EXP-006 EWMA 점수 누적 + 아키텍처 종합

## 목적·가설

EXP-004~005에서 남은 마지막 사각인 corr_break를 점수 시계열 누적(EWMA)으로 감지할 수
있는지 검증하고, 전 실험 결과를 종합해 감지 아키텍처를 확정합니다. 가설은 "PCAX의
윈도우당 약 3sigma 지속 신호를 EWMA가 누적하면 단발 임계의 병목을 넘는다"입니다.

## 설정

- 방식: PCAX(상관 피처) 점수 → 상한 3.0 클리핑(winsorize) → EWMA(alpha 0.1) →
  학습 정상 시퀀스로 재캘리브레이션한 분위수 한계(q0.999)와 비교
- alpha 스윕 (0.1/0.2/0.3): 0.1이 corr_break 한계 초과비율 0.91~0.95로 최고, 정상
  오탐 최소라 채택. 시정수 약 10 윈도우(120 tick)
- 클리핑 도입 경위: 미적용 시 점화 램프의 거대 점수가 느린 감쇠로 수백 tick 오탐
  꼬리를 만들어 오탐 293건, 상한 3.0 적용 후 134건
- config: exp_006_pcax_ewma (유예 60) / exp_006_g180 (유예 180, 완만 전개 이상 기준)

## 결과

| 지표 | EXP-006 (유예 60) | EXP-006 (유예 180) | 참고: 규칙 (유예 60) |
| --- | --- | --- | --- |
| event_recall | 0.773 | **0.909** | 0.864 |
| recall_corr_break | 0.00 | **1.00** | 0.00 |
| recall_oscillation | 0.50 | **1.00** | 1.00 |
| recall_drift_inband | 0.00 | 0.00 | 0.00 (원리적) |
| 오탐/설비·일 | 19.9 | 19.9 | 116.7 |

corr_break 상세: 감지 지연 119/131 tick(약 10~11분), 이상 구간 한계 초과비율
0.91/0.95로 일회성 적중이 아닌 지속 감지입니다. 오탐 134건의 구성은 점화 모드 전이
70건(52%, 규칙은 동일 지점 237건)과 EWMA 꼬리로 번진 배경 이탈 64건입니다.

## 결론: 감지 아키텍처 확정

corr_break가 뚫렸습니다. 규칙 레이어가 영원히 못 잡는 이상을 11분 내 지속 신호로
감지하며, 남은 미감지는 유예 대비 전개가 느린 in-band 드리프트뿐입니다 (유예 밖
419~695 tick에서는 감지됨). 전 실험을 종합한 확정 아키텍처는 다음과 같습니다.

| 레이어 | 담당 | 근거 실험 |
| --- | --- | --- |
| 결정론 임계 (기존 유지) | 급성·안전 한계, 포인트 단위 즉시 | EXP-004 (급성·진동 최속) |
| v0 raw 경로: PCAX 단발 임계 | 급성·드리프트·in-band 드리프트, 저오탐 | EXP-002~004 (오탐 -99.3%) |
| v0 누적 경로: PCAX + EWMA | 상관 붕괴 등 지속 저강도 이상 | EXP-006 (초과비율 0.91+) |
| LLM | 판정 결과 설명 (T²/SPE 채널 기여도 근거) | D1·D2 |
| v1 (TS2Vec) | 보류, 실측 데이터 확보 후 재검토 | EXP-005 |

raw 경로와 누적 경로는 같은 PCAX 점수의 두 가지 소비 방식이라 모델은 하나입니다.

## 한계와 후속

- EWMA 경로 오탐(배경 64건)은 raw 경로(32건)보다 높습니다. "지속 K 윈도우 초과 시
  알람" 확인 규칙 추가로 억제 가능하며 서빙 설계 시 반영합니다
- 점화 모드 전이 오탐은 전 레이어 공통 구조 문제로, 실서비스에서는 레시피 상태
  신호로 마스킹하는 것이 정석입니다 (모델 측 해결은 다중 모드 은행, 보류된 v1 주제)
- 설비별 캘리브레이션(동일 공정 내 기체 차)은 합성 데이터로 검증 불가, 실측 데이터
  확보 후 별도 실험으로 진행합니다
- 유예 180 채점은 corr_break류 완만 이상에만 의미가 있으며, 급성 계열 비교는 유예
  60 결과를 기준으로 유지합니다


## 재캘리브레이션 후기 (2026-07-30, ADR-0011)

본 문서 표는 실험 시점(전 유형 공통 유예, 오탐 raw FAR) 기록으로 보존합니다. 2026-07-29 [ADR-0011](../adr/0011-anomaly-eval-metrics.md) 재캘리브레이션으로 유형별 감지 유예(drift_inband 720 tick)와 dedup FAR이 도입되어 `experiments/results/` 스냅샷이 재기록되었습니다. drift_inband이 감지로 전환되어 event_recall이 상향되었습니다(유예60 0.773→0.864, g180 0.909→1.000). "남은 미감지는 in-band 드리프트뿐" 서술은 유예 720 하에서 초과됩니다. 현재 기준 수치는 재기록 스냅샷과 [anomaly-model-summary.md](anomaly-model-summary.md)를 따릅니다.
