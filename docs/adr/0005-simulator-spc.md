# ADR-0005: 시뮬레이터 SPC 이상 데이터 생성 모델

- 상태: 승인 (2026-07-09)
- 결정자: 주희정
- 관련: [ADR-0001](0001-architecture.md), [docs/simulator.md](../simulator.md), feature/23-simulator-spc(#24), feature/50-simulator-demo(#51), feature/64-simulator-clamp(#65)

## 배경

시뮬레이터는 실제 설비를 대신해 센서값을 생성·적재하며, 에이전트가 진단할 데이터의 최상류
공급원입니다(역할·구조는 [docs/simulator.md](../simulator.md) 참조). 본 ADR은 그 데이터 생성
모델을 **왜 SPC 동적 밴드로 정했는지**와, 데모 안정화 과정에서 추가한 **값 폭주 클램프·게인·
프리셋 결정**을 기록합니다.

## 결정

### 1. 1차 지연 모델 → SPC 동적 밴드로 전면 재작성 (feature/23 #24)

초기 모델은 고정 임계값(예: 온도 65도)에 지수 점근하는 1차 지연 방식이었습니다. 이 방식으로는
실제 SPC 관측, 드리프트·PM(예방 정비), 다변량 복합 이상을 표현할 수 없었습니다. 각 변수를
`VariableSpec(mu0, sigma, band, LSL, USL, drift_rate)`로 정의하고 중심선(mu0+드리프트) ±3σ
밴드가 함께 이동하는 SPC 모델로 재작성했습니다. 알람은 급성·냉각급성·드리프트·변동성 증가·
다변량 붕괴를 판정하며 우선순위로 대표 1건을 선정합니다.

### 2. 순수 함수 + 연속 2 tick 확정 분리

생성 로직(`generator.py`)은 DB·시간 의존 없는 순수 계산으로 두어 단위 테스트가 결정론적으로
동작하게 했습니다. tick 후보 산출은 generator가, 연속 2 tick 지속 확정은 상위 실행부
(`main._confirm_persistence`)가 담당해 1 tick 스파이크를 걸러냅니다.

### 3. 데모 가시성: 프리셋·게인 (feature/50 #51)

- `floor_demo` 프리셋은 설비별로 서로 다른 시나리오를 배치해, 3D 씬에서 정상 다수·경고·이상이
  한눈에 구분되도록 합니다(단일 target 시나리오의 한계 보완).
- 실측 드리프트가 너무 느려 데모에서 보이지 않는 문제를 `--gain` 배수로 해결하되, 게인은 PM
  드리프트에만 적용합니다. err402·다변량 레이트에 게인을 곱하면 1 tick 폭주가 발생하기 때문에
  의도적으로 제외했습니다.
- 프리셋 실행 중에도 로그가 `scenario`로만 찍히던 오표기를 실행 모드 분기로 정정했습니다.

### 4. 값 폭주 클램프 (feature/64 #65)

PM 드리프트는 하드리밋 회랑 소진 시 포화되지만, err402·다변량(비드리프트 경로) 중심선은
무한 발산했습니다(온도 540, 압력 -999 등). `FAULT_OVERSHOOT`(0.5)로 하드리밋 밖 ±0.5·span까지만
포화하도록 클램프했습니다. PM 경로(밴드 내 포화)와 급성·다변량 경로(하드리밋 밖 일부 허용)는
서로 다른 상한을 씁니다.

## 대안 검토

| 대안 | 기각 사유 |
| --- | --- |
| 1차 지연 + 고정 임계값 유지 | SPC 관측·드리프트·다변량 표현 불가 |
| 모든 경로 동일 포화 상한 | 급성 알람이 밴드 밖으로 못 나가 판정 불가 |
| 게인을 전 경로 적용 | err402·다변량이 1 tick 폭주 |
| 시간 의존 생성 | 단위 테스트 비결정성, DB 없는 검증 불가 |

## 결과 / 미해결

- 정상 프로파일은 Etching만 참고서 실측 기반이고 Deposition은 라인 구분용 데모 파생값이라
  정확도를 보증하지 않습니다.
- `FAULT_OVERSHOOT`·`VARIANCE_MULT`는 물리 근거보다 데모 알람 확정 안정성 기준으로 튜닝한
  경험값입니다(VARIANCE_MULT는 최신 tick 판정 전환 후 2.5→3.5로 상향).
- `sensor_log_max_rows`(500) 최근 편향으로 장기 추세 질의에서 오래된 구간이 잘릴 수 있으며,
  이는 [ADR-0003](0003-agent-runtime-budget.md)의 컨텍스트 방어 결정과 연동됩니다.
