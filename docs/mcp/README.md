# MCP 서버

본 시스템은 데이터 소스를 MCP(Model Context Protocol) 표준 도구로 추상화합니다(REQ-T-02).
정형 데이터와 비정형 지식을 각각 담당하는 두 서버로 구성됩니다.

| 서버 | 담당 도구 | 문서 |
| --- | --- | --- |
| realtime | 센서 로그·알람 집계·설비 메타데이터 | [realtime.md](realtime.md) |
| knowledge | 매뉴얼 유사도 검색·유사 사례 검색 | (예정) |

에이전트(MCP 클라이언트)는 두 서버의 도구를 동일한 방식으로 발견·호출하여, 정형
데이터와 비정형 지식을 종합한 답변을 생성합니다.
